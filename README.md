# Wario
Play this platformer game and try to not touch the ground!
link to try: https://wario-nine.vercel.app/

# how to play
- move mouse left to move left
- move mouse right to move right
- move mouse onto player to stop moving
- press space to jump
- if you open inspect window, game will say you win, once there are no more platforms left
- if you lose, you just restart again

Don't forget to have fun!
